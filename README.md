# بورتفوليو شخصي قابل للتعديل

هذا المشروع بورتفوليو ثابت ثنائي اللغة، جاهز ليعمل على GitHub Pages. جميع المعلومات الحالية **تجريبية**؛ لا تنسَ استبدالها قبل النشر.

## المكان الوحيد لتعديل المحتوى

افتح الملف التالي في VS Code:

```text
client/src/data/portfolio.ts
```

ستجد فيه الاسم، المسمى الوظيفي، البريد، المدينة، روابط GitHub وLinkedIn، النصوص، المهارات، والمشاريع. كل نص مكتوب مرتين: `ar` للعربية و`en` للإنجليزية. لا تعدّل بناء الصفحة داخل `Home.tsx` إذا كان هدفك فقط تغيير المعلومات.

## تعديل مشروع أو إضافة مشروع جديد

داخل `portfolio.ts` توجد قائمة باسم `projects`. كل مشروع يحتوي على عنوان ووصف وتصنيف وحالة وتقنيات وصورة ورابط. عدّل القيم الموجودة، أو انسخ كتلة مشروع كاملة وألصقها تحتها لإضافة مشروع جديد.

مثال مبسط:

```ts
{
  number: "04",
  title: { ar: "عنوان المشروع", en: "Project title" },
  category: { ar: "موقع ويب", en: "Website" },
  status: { ar: "مكتمل", en: "Complete" },
  description: { ar: "وصف عربي قصير.", en: "A short English description." },
  stack: ["React", "CSS"],
  image: "ضع-رابط-الصورة-هنا",
  link: "https://github.com/your-username/project-name",
}
```

## تعديل صور المشاريع

لكل مشروع سطر باسم `image`. ضع فيه رابط الصورة مباشرة. أفضل طريقة للنشر عبر GitHub هي رفع الصور إلى مجلد مثل `client/public/images/` ثم كتابة رابطها بهذا الشكل:

```ts
image: "/images/my-project.jpg"
```

يمكنك أيضًا استخدام رابط صورة خارجي موثوق. اجعل الصورة أفقية تقريبًا بنسبة `4:3` كي تظهر بصورة مناسبة في البطاقات.

## التجربة محليًا

بعد فتح المجلد في VS Code، نفّذ:

```bash
pnpm install
pnpm dev
```

## النشر إلى GitHub Pages

ارفع المشروع إلى مستودع GitHub، ثم اذهب إلى **Settings → Pages** واختر **GitHub Actions** كمصدر للنشر. يوجد ملف إعداد نشر جاهز داخل `.github/workflows/deploy.yml`. بعد رفع التعديلات إلى الفرع `main`، ستبني GitHub الموقع وتنشره تلقائيًا.

> تذكّر تغيير روابط GitHub وLinkedIn والبريد الإلكتروني التجريبية قبل النشر.
